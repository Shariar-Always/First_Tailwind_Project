A modern, responsive landing page for **Smart Coders: Learn Programming**, built with the latest **Tailwind CSS v4**, **HTML5**, and **Vite**.

---

## 🌐 Live Demo
- **Live Preview:** [https://shariar-always.github.io/First_Tailwind_Project/](https://shariar-always.github.io/First_Tailwind_Project/)

---

## ✨ Features
- **Responsive Layout:** Optimized across mobile, tablet, and desktop screens with Tailwind's breakpoint utilities.
- **Modern Dark Theme:** Styled with deep dark backgrounds (`#2B2D33`) and vivid accents (`#F65023` & Indigo).
- **Navigation Bar:** Responsive sticky header with brand logo and navigation links.
- **Hero Section:** Eye-catching call-to-action with pulse animations and customized SVG icons.
- **Services Grid:** Responsive card grid highlighting web development services and course offerings with interactive hover borders.
- **Utility-First Styling:** Clean, maintainable UI built with Tailwind CSS v4.

---

## 🛠️ Built With
- **Tailwind CSS v4** - Next-generation utility-first CSS framework
- **HTML5** - Semantic markup
- **PostCSS** - CSS processing
- **Vite** - Lightning-fast frontend build tool

## 🚀 Getting Started Locally

```bash
# 1. Clone the repository
git clone https://github.com/Shariar-Always/First_Tailwind_Project.git

# 2. Navigate to the project directory
cd First_Tailwind_Project

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```
